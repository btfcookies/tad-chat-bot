# TAD Chat Bot Framework
This is the official framework for those who want to build bots for TAD Chat. 

## Prereqs
- Node & npm

thats it!

## Getting started
1. Fork and clone the repo
2. Run `cp .env.example .env` in your terminal (make sure you're in the right folder)
3. Run `npm start` to start your bot
4. Type a message and hit enter in the terminal. You'll see this message appear in the forum selected in .env

5. **IMPORTANT:** After setting up your bot, you must go to the [main TAD Chat repo](https://github.com/btfcookies/tad-chat) and make a pull request to add your bot's name to the bot list. Failure to do so within 24 hours of creating your bot could lead to a ban. Click [here](https://github.com/btfcookies/tad-chat/BOTS.md) for more guidance on how to do this.
